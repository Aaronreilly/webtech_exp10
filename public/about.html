About TechHub

Technology, made easy to explore.

TechHub is a sample technology product showcase website created to present modern electronic products in a clean and organized way.

Visitors can browse product categories, view brief descriptions and compare sample prices. This project demonstrates how a Node.js server can receive HTTP requests and deliver web pages to a browser.

Technology used: Node.js, built-in HTTP module, HTML and CSS.
