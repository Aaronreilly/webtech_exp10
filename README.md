# Tech Product Showcase - Node.js Lab Experiment

## Requirements
- Node.js installed
- Visual Studio Code (recommended)

## Run the project
1. Extract this folder.
2. Open the `TechProductShowcase` folder in VS Code.
3. Open the terminal in that folder.
4. Run:

   node server.js

5. Open http://localhost:3000 in your browser.

## Routes to test
- http://localhost:3000/          Home
- http://localhost:3000/home      Home
- http://localhost:3000/products  Products
- http://localhost:3000/about     About
- http://localhost:3000/contact   Contact
- http://localhost:3000/unknown   Demonstrates the 404 response

## Notes
This project uses only Node.js built-in modules; no npm packages are required.
The product names and prices are sample showcase content. The contact form is a front-end demo and does not send messages.
